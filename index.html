▶怎么玩？
  1. 开启摄像头，等模型加载完（顶部圆点变绿）。
  2. 对镜头做一个表情，点对应预设或填名字后录制，保持 0.6s。
  3. 多录几个（中性 / 开心 / 惊讶 / 生气 / 难过…），小克就会实时跟着切换。
  4. 飞吻：把手靠近嘴边再向外推开 → 触发爱心。（独立于表情识别）
  5. 点某条基准可编辑它的心情 / 台词 / emoji / 粒子 / GIF。
  6. 关键点有偏移就进校准模式拖一拖。
所有数据存在本机浏览器（localStorage），刷新仍在。需要摄像头权限；若打不开摄像头，请用本地服务器或 https 打开本页。
